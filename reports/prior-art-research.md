# v3.9.0 Prior-Art Research

Date: 2026-09-04

## Scope

This release is a targeted update to an established public skill, not a new-skill discovery project. The requested change was to absorb the public prompting techniques from Anshu Chimala's Lenny's Newsletter article, preserve the existing qiaomu-design workflow, and publish it safely. A fresh catalog ranking was not run; adoption, ratings, and current comparative quality are therefore `missing evidence` for this release.

## Sources actually inspected for this iteration

1. Anshu Chimala, “How to turn your AI into a world-class designer” — public Technique 1–6 only. Learned: random creative seeds, ambitious non-software metaphors, user reaction as direction data, compact build briefs, screenshot-only independent critique, and deliberate media/tool selection.
2. Sakana AI, “String Seed of Thought” — learned: random strings can diversify generation without treating the seed as product content or factual evidence.
3. The existing qiaomu-design source package and its maintained references — inspected to map the new mechanisms onto the established design read, dials, functional contract, four-direction preview, craft loop, engineering checks, and self-evolution protocol without duplicating them in the root entrypoint.

## Keep / adapt / reject / invent

- Keep: Discover → Define → Deliver as an understandable creative arc; independent visual criticism; deliberate subtraction.
- Adapt: creative seeds are private, reproducible inputs mapped to explicit design axes and bounded by function, brand, readability, accessibility, and performance.
- Reject: any implication that random strings alone create good design; any guess about paywalled Technique 7+; any automatic external-model call.
- Invent: connect creative seeds to four mutually exclusive direction briefs, user-confirmed preview selection, a project-level `DESIGN.md`, and the existing evidence-backed self-evolution state machine.

## Existing lineage retained, not re-benchmarked here

The package already credits and routes to mechanisms previously derived from Anthropic frontend-design, Vercel Web Interface Guidelines, Emil Kowalski skills, taste-skill, IBM Carbon, impeccable, extract-design-system, design-an-interface, and VoltAgent/awesome-design-md. This packaging pass did not rerun the historical 42-page or 80-page comparisons and does not claim new superiority over those sources.

## Missing evidence

- No fresh skills.sh or SkillsMP catalog metrics.
- No provider-backed A/B comparison of v3.8 versus v3.9 creative diversity.
- No new human blind review for the compact root entrypoint.
- Publication, discovery, and clean-install evidence are produced separately by the release workflow.
